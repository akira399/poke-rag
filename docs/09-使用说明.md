# 09 · 使用说明（零基础版）

> 你就需要一条路：**双击一个文件 → 浏览器里聊天**。本文讲清楚所有细节。

---

## 一、最省事：双击一键启动

在 `poke-rag` 文件夹里找到 **`start_poke_rag.bat`**，双击它：
1. 会自动打开两个黑色命令行窗口（后端 + 界面，**不要关它们**）；
2. 约 10 秒后浏览器自动打开 **http://localhost:8501**；
3. 在输入框打字提问即可（比如「快龙怕什么属性？」）。

**关闭**：把两个命令行窗口直接关掉（或红叉）即可。

## 二、手动启动（备选，和上面等价）

```bash
cd poke-rag
EMBED_DISABLED=1 .venv/Scripts/python.exe scripts/serve.py      # ① 后端（第一个黑窗口）
.venv/Scripts/python.exe scripts/serve_ui.py                     # ② 界面（第二个黑窗口）
# 浏览器打开 http://localhost:8501
```

## 三、能问什么（示例，框内问题都现答现引）

| 类型 | 例子 |
|---|---|
| 图鉴 | 快龙是什么属性？皮卡丘有什么特性？喷火龙的种族值是多少？ |
| 属性克制 | 快龙怕什么属性？暴鲤龙怕什么？ |
| 招式 | 十万伏特的威力是多少？龙之舞有什么效果？ |
| 特性 | 硬壳盔甲有什么效果？多鳞的效果是什么？ |
| 道具 | 大师球的效果是什么？生命宝珠呢？ |
| 对战环境（Meta） | 现在 Gen9 OU 环境最热门的宝可梦是谁？UU 环境使用率第一？ |
| 应当拒绝的 | 今天上海的天气？（会诚实说"知识库中未找到"，演示亮点） |

**每个答案都带 [1][2] 引用编号，点开就是信息来源卡片——答必有据。**

## 四、界面三个页签

- **💬 问答**：打字 → 流式回答 → 引用可点开；
- **🔍 检索调试**：输入问题，看到"这一问命中了哪些知识卡片、各自得分"（面试演示用）；
- **⚙️ 模型设置**：想换模型（DeepSeek/通义/Kimi/OpenAI…）就在这里填 base_url / API Key / 模型名，保存即生效。**当前已配好 DeepSeek 最便宜的档（v4-flash）**。

## 五、常见问题

| 现象 | 原因与处理 |
|---|---|
| 浏览器打不开 8501 | 界面黑窗口报错？告诉我报错内容；或先确认后端 8765 已在运行 |
| 回答"知识库中未找到" | 说明该问题超出知识库（或表述太泛）——这是**设计行为**，试试换个说法 |
| 想换更强检索 | 已运行"向量+关键词"双路混合检索（mE5-small 本地模型，评测 99% 答案可见率），无需设置 |
| 输入了 API Key 保存后不生效 | 保存后重启一次界面（关黑窗口重开），或检查 base_url 是否以 `/v1` 结尾以外的格式（DeepSeek: https://api.deepseek.com 即可） |

## 六、想换/重装数据（一般不用）

数据是"可再生的"（脚本在 git 里，一键重建）：

```bash
.venv/Scripts/python.exe scripts/fetch_pokeapi.py     # PokeAPI 全量（约 25 分钟）
node scripts/fetch_showdown.mjs                        # Showdown 规则数据
.venv/Scripts/python.exe scripts/fetch_smogon.py       # Smogon 环境榜（自动最新月）
.venv/Scripts/python.exe scripts/build_cards.py        # 生成全部知识卡片
EMBED_DISABLED=1 .venv/Scripts/python.exe scripts/build_index.py   # 重建检索索引
```
