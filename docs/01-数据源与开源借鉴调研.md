## 一、数据源核验（这是知识库的"面粉"，选料先于开工）

### 1.1 PokeAPI —— 图鉴结构化主数据（首选）

| 项 | 数据 |
|---|---|
| 仓库 | `PokeAPI/pokeapi` · **5,370★** · 最后提交 2026-09-02（当日） |
| 许可 | **BSD-3-Clause**（可商用、可再分发，只需保留声明） |
| 内容 | 1025 只宝可梦全量：属性/种族值/特性/进化链/图鉴描述（多语言）/招式/道具/生蛋组等 |
| 接口 | `https://pokeapi.co/api/v2/pokemon/{id}` 等 |

**实测关键结论（本轮直接验证过）**：
- `/pokemon-species/149` 返回的 `names` 字段**含官方简体中文名**（`zh-hans: 快龙`）与繁体（`zh-hant: 快龍`），`flavor_text_entries` 同样含 **zh-hans 图鉴描述**——**中文问答不需要自造翻译表**，用官方名即可。
- 同仓库的 `PokeAPI/api-data`（189★）提供**静态 JSON 快照 + JSON Schema**，可 clone 到本地离线取数（教学点：静态快照 vs 在线 API 的区别——企业里就是"数据仓库 vs 线上数据库"）。

**获取策略**：`api-data` 静态快照为主 + 在线 API 补齐缺失资源（分页/重试/续传）。PokeAPI 在线额度宽松无 Key，但 1 万+ 请求仍要写优雅的限速与缓存（教学点）。

### 1.2 Pokémon Showdown —— 对战规则权威数据（L2/L4 核心）

| 项 | 数据 |
|---|---|
| 仓库 | `smogon/pokemon-showdown` · **5,867★** · 最后提交 2026-09-02 · 许可 **MIT** |
| 内容（`data/` 目录，本轮已确认文件清单） | `typechart.ts`（**属性克制表**）、`moves.ts`（1000+ 招式效果）、`abilities.ts`（特点效果文本）、`items.ts`（道具）、`learnsets.ts`（每只可学招）、`formats-data.ts`（**分级 OU/UU/UBER…**）、`conditions.ts`（天气/场地）、`natures.ts`、`aliases.ts`（**又一组别名，可借鉴**）、`text/` |
| 用途 | ① 克制表→查表规则引擎 ② 招式/特性/道具效果文本→知识卡片 ③ 分级→Meta 知识 |

**注意**：数据文件是 TypeScript 源码（`export const X = {...}`），取数需转 JSON（见方案 §11 风险与备选）。Showdown 同时是全球最大的对战模拟器，其数据修正永远跟官方同步——引用它 = 引用"实时同步的规则库"。

#### 取数路线验证记录（2026-09-02 预研实测通过 ✅）

**路线**：`curl 下载 data/*.ts → esbuild 转译（--format=cjs）→ node require → dump JSON`。用本地已有 esbuild（小程序仓库 node_modules，无需新装依赖）。

**实测数据**（smogon/pokemon-showdown master 分支，2026-09-02）：

| 文件 | 大小 | 转译后键数 | 抽查 |
|---|---|---|---|
| typechart.ts | 6.7 KB | 19（18 属性 + 附加） | 属性伤害倍率正确 |
| pokedex.ts | 538 KB | 1,518（含 Mega/地区形态） | 快龙：Dragon/Flying、种族值、特性 Inner Focus/Multiscale 全对 |
| learnsets.ts | 3.7 MB | 1,289 | 加载通过 |
| natures.ts | 1.5 KB | 25 | 加载通过 |
| aliases.ts | 72 KB | 2,553（含格式别名 Gen 9 OU 等） | **额外收获**：Showdown 自带别名表，可并入 M1 别名表 |

**M0 取数脚本定案**：`scripts/01_fetch_showdown.py`（或 node）按此路线把 12 个 data 文件统一 dump 为 `data/raw/showdown/*.json`。npm 包 `pokemon-showdown@0.11.11`（147MB）留作后备。

### 1.3 Smogon 对战 Meta（L3 非结构化文本的主力）

| 来源 | 内容 | 说明 |
|---|---|---|
| `smogon.com/stats/` | 月度使用率（各 tier Top 榜，JSON/CSV 直接下载） | **注意**：这是"环境 meta 答案"的来源，比如"当前 OU 环境使用率第一是谁"——这类问题 PokeAPI 答不了，**是本项目的差异化** |
| `smogon.com/dex/sv/pokemon/{name}/` | 战术分析文章：能力概述/持有道具/EV 分配/队友建议 | 纯英文、半结构文本（标题+段落）——**最贴近企业"业务文档/行业报告"的 RAG 素材** |
| `smogon/damage-calc`（**531★**，MIT，最后提交 2026-08-28） | 伤害公式与全部修正系数（官方对战伤害计算器） | 作为 **M5 对拍参照**：我们自研 Python 伤害引擎与它跑 100 组对照，公式对错一测便知 |

### 1.4 中文名补充

官方繁/简中名 PokeAPI 已自带（1.1 实测）。需补充的只是**玩家俗称**（如"肥大"）与少量版本译名——检索兜底用，量小（几十条），M1 手工录入即可。**不要**用第三方中文数据集（搜到的 `peter890331/Pokedex_JSON` 仅 0★，繁中为主、质量不明），官方名是唯一正确选择。

## 五、调研结论（决策依据汇总）

1. **数据面**：全部权威开源、许可宽松（BSD-3 / MIT），PokeAPI 官方简体中文名实锤存在——**零版权/零翻译风险**。
2. **需求面**：宝可梦 RAG 已有 406★ 成熟项目，证明选题成立且有受众；但它们是"重型武器+黑盒框架"，我们的定位是"轻量自研+每一步讲透"，反而差异化。
3. **评测面**：连课程项目都做评测了——我们的 100 条/6 类评测集是**及格线之上**的准备。
4. **风险面**：Showdown TS→JSON 提取是唯一技术风险点，M0 首日验证，有 3 条备选路线，不会阻塞。
