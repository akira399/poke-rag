# 00 · 技术方案（开源版）

> 基于 RAG 的宝可梦对战知识库问答系统。本文介绍系统设计与实现。

## 1. 项目定位

宝可梦对战知识库问答系统：覆盖图鉴、招式、特性、道具、属性克制、
对战环境（Meta）与伤害计算。数据全部来自权威开源数据源（PokeAPI /
Pokémon Showdown / Smogon），知识可溯源、答案可量化评测。

选型理由：对战数据**权威且完整**、**评测客观**（克制/伤害有标准答案）、
**知识形态多样**（结构化主数据、规则知识、非结构化战术文本、可计算知识）——
四种形态与通用企业知识库同构。

## 2. 系统架构

```
展示层  Streamlit（问答 / 检索调试 / 伤害计算器 / 模型设置）
        ↓ HTTP + SSE
服务层  FastAPI（/api/chat /api/search /api/settings /api/health）
        ↓
编排层  Router（意图路由）
   ├─ 工具路径：招式集合查询/伤害计算 → 规则引擎
   └─ 知识路径：检索 → 重排 → 组装上下文 → LLM 生成 → 引用校验/拒答
        ↓
数据层  知识卡片（pokemon/move/ability/item/meta）
   ├─ 向量库（Chroma，可选 dense）
   └─ BM25 索引（jieba + 自定义词典）
```

## 3. 数据层

- 来源：PokeAPI（结构化+官方简体中文名）、Pokémon Showdown（规则/招式/
  特性/道具/克制表/学习表）、Smogon（月度使用率环境榜）；
- 管道：`fetch_pokeapi.py` / `fetch_showdown.mjs` / `fetch_smogon.py` →
  `build_cards.py`（知识卡片生成）→ `build_index.py`（检索索引）；
- 知识卡片：每张卡 = 自然语言正文（检索/生成用）+ 结构化字段（规则引擎用）
  + source 来源（引用溯源）；
- 本地化：PokeAPI 官方简体中文名 + 补丁表（官方缺失的实体用通行译名）。

## 4. 检索层

- 双路召回：稠密（bge-m3 / mE5-small 可切换，本地模型）+ BM25（jieba 分词，
  卡片标题灌入自定义词典修复专名破碎）；
- 融合：RRF（名次融合，免调参）；
- 查询改写：术语表（会心一击→critical hit）+ 实体别名扩展（快龙→Dragonite），
  解决中英无词重叠；
- 配置 `rag.use_dense`：按消融结果默认关闭轻量向量（见 docs/05 评测）。

## 5. 生成层

- 模型可配置（OpenAI 兼容协议，界面填 base_url/key/model）；
- 反幻觉：提示词约束（只依据知识片段/强制引用/承认未知）+ 引用编号校验 +
  检索置信度闸 + 评测兜底；
- 工具路由（Agentic RAG）：招式集合查询（所有/变化招式）由规则引擎计算，
  结果作为事实上下文注入。

## 6. 规则引擎

- 属性克制：Showdown typechart 查表，写入卡片；
- 伤害计算：Gen9 官方公式逐项复刻（随机档前置/逐项取整/pokeRound/定点 STAB），
  与官方 @smogon/calc 对拍 100 例精确一致（Δ=0）；
- 招式查询：learnsets + moves 融合（攻击招式按威力降序/变化招式分组）。

## 7. 评测

- 检索：78 问 / 5 类，top-3 99%（`eval_retrieval.py`）；
- 消融：查询改写层 top-3 +8%（`ablation.py` 可复现）；
- 伤害：官方对拍 86/86（`verify_damage.py`）；
- 单测：pytest 51 例（纯函数，不依赖网络）。

## 8. 运行

```bash
pip install -r requirements.txt            # 见依赖清单
python scripts/build_cards.py              # 生成知识卡片
python scripts/build_index.py              # 构建检索索引
python scripts/serve.py                    # 后端（8765）
python -m streamlit run scripts/serve_ui.py  # 界面（8501）
```

## 9. 目录

```
src/
  pipeline/   数据管道（normalize / aliases / build_cards / typechart / i18n_patch）
  retrieval/  检索（embed / bm25 / hybrid / index / query_expand）
  generation/ 生成（llm / prompt / rag）
  rules/      规则引擎（damage / move_query）
  api/        FastAPI
  config.py   配置加载（config.local.json，gitignore）
scripts/      采集 / 建卡 / 建索引 / 检索 / 评测 / 消融 / 服务
tests/        pytest 单测
data/         可重建资产（不入 git，脚本一键生成）
```

## 10. 里程碑

M0 数据管道 → M1 知识卡片 → M2 检索（双路+RRF+查询改写）→ M3 生成
（流式+引用+拒答）→ M4 门户（API+UI+克制规则）→ M5 调优（伤害对拍/评测/消融）。
